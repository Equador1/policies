# policies

Politiques de confidentialité publiées pour les projets privés, servies par GitHub
Pages à `https://equador1.github.io/policies/`.

Ce dépôt est public parce que GitHub Pages l'exige, et parce que ces textes sont destinés à être
lus : les boutiques d'extensions demandent une adresse publique vers la politique du produit.

## Un projet, un dossier

| Projet | Fichier source | Adresse publiée |
|---|---|---|
| Contrôle Parental Web | `parental-control/index.md` | https://equador1.github.io/policies/parental-control/ |

Pour ajouter un projet : créer un dossier en minuscules sans accents, y mettre un `index.md`
commençant par un front matter YAML (`---` / `title: ...` / `---`), et pousser sur `main`.
Sans ce front matter, Jekyll ne convertit pas le Markdown et la page est servie en texte brut.

## Tenir les copies synchronisées

Chaque politique existe en double : ici, et dans le dépôt du projet privé concerné (par exemple
`PRIVACY.md`). La date de mise à jour en tête de chaque page sert à repérer un décalage entre les
deux. Quand la politique d'un projet change, modifier les deux.
